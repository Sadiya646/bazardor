# 🛒 বাজার দর | BazarDor

## About the Project
BazarDor is a responsive web application that helps users check and compare the prices of essential products in Bangladesh.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- React Hot Toast
- REST API

## Features
1. View essential product prices in Bangladesh.
2. Browse products by category.
3. Track daily price increases and decreases.
4. Compare prices across different markets.
5. Sort products by price.
6. View detailed product information.
7. Sign up and sign in using email and password.
8. Sign in using Google and GitHub.
9. Responsive design for mobile, tablet, and desktop.
